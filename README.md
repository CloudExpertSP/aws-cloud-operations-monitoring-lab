# AWS Cloud Operations & Monitoring Lab

A hands-on learning project focused on AWS infrastructure, cloud operations, monitoring, security, and troubleshooting.

## 🎯 Objectives

- Learn to provision and manage AWS infrastructure.
- Practice cloud monitoring and operational health checks.
- Develop Linux troubleshooting skills.
- Understand IAM permissions and basic cloud security.
- Document common operational issues and their resolutions.

## 🛠️ Technologies

- **Cloud:** Amazon Web Services (AWS)
- **Compute:** Amazon EC2
- **Networking:** Amazon VPC
- **Identity & Access:** AWS IAM
- **Monitoring:** Amazon CloudWatch
- **Operating System:** Linux
- **Version Control:** Git and GitHub

## 📋 Planned Lab Activities

- [ ] Document the AWS architecture and setup.
- [ ] Create and configure a test EC2 instance.
- [ ] Review security groups and least-privilege access.
- [ ] Configure basic CloudWatch monitoring.
- [ ] Practice Linux system checks and troubleshooting.
- [ ] Document test scenarios, findings, and cleanup procedures.

## 🔐 Security Practices

- Never commit AWS access keys, passwords, tokens, or private keys.
- Use IAM roles and least-privilege permissions where applicable.
- Avoid publishing confidential information or employer-owned material.
- Review AWS resources and delete lab resources when finished to control costs.
